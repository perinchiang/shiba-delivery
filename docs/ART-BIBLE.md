# 阿柴快送｜轻量美术规范基线（Art Bible Index）

> 本文是《阿柴快送》的**单一美术与技术美术约束索引**，只收敛散落规范、明确裁决规则与预算红线；不复制 [`GAME.md`](GAME.md)、[`FIRST-ROAD.md`](FIRST-ROAD.md) 或 [`art/morning/README.md`](../art/morning/README.md) 的长文，具体实现细节以引用源文件为准。

---

## 1. 视觉定位与裁决测试

**一句话定位**：清晨暖侧光下的立体微缩动物小镇——清晰圆润的卡通大轮廓、温润克制的南国街景色板、轻快干净的可读空间。

遇到视觉分歧时，按以下 3 条测试裁决：

1. **辨识度优先于写实细节**：当繁复写实纹理与中远距轮廓可读性冲突时，选大色块、清晰体块与干净边缘。
2. **主体永远压住背景**：阿柴（暖橘/奶油毛色 + 头盔 + 领巾）与红色/暖色系小摩托在任何路段必须一眼跳出，建筑墙面与路面保持低对比烘托。
3. **可玩与可达优先**：任何路缘、树池、店招、红绿灯或装饰 props 不得遮挡主视角操作路线或制造假碰撞；步行/骑行通道必须一眼可辨。

## 2. 色板与光影基线

- **唯一色板事实源**：[`src/morning/city-palette.js`](../src/morning/city-palette.js) 中的 `CITY_PALETTE`。
  - 墙面以奶油/杏/鼠尾草绿/橄榄/暖沙/浅粉为主；瓦顶与强调色用青瓷绿（`teal` / `jade`）与陶土红（`terracotta` / `lantern`）；路面用深灰冷沥青（`asphalt`）压稳画面并衬托暖黄/米白标线。
  - 新增城区建筑、街具、小店 props **必须优先复用或微调自 `CITY_PALETTE`**，禁止凭空引入高饱和霓虹色或刺眼纯白/纯黑。
- **时段与光影**：当前基线为**清晨暖侧光**，远景用柔和薄雾压低对比度；仅近处主体投射阴影。

---

## 3. 比例、造型与坐标红线

- **单位与缩放**：全项目使用**米制**。阿柴与小摩托的卡通比例已锁定，游戏中统一按 **`0.84`** 放入街景；禁止为迎合写实上下车动作而拉长角色腿部或缩小车身（见 [`GAME.md`](GAME.md) §3/§8）。
- **坐标系约定**（详见 [`art/morning/README.md`](../art/morning/README.md)）：
  - Blender 源场景：X 为横向、Z 向上、车头朝 `-Y`。
  - 导出 glTF / Three.js：Y 向上、车头朝 `+Z`。
  - 角色/摩托接触锚点（`Seat_Contact`、`Grip_L/R`、`Footrest_L/R`、`Cargo_Floor`、`Cargo_Approach`、`soleDepth`）由脚本与游戏共享，修改造型必须同步保活 `npm test` 几何断言。
- **树木与自然造型**：短胖蜜棕树干 + 圆根贴地 + 连成一体的偏心分层冠面 + 立体宽叶顶点色明暗（详见 [`GAME.md`](GAME.md) §3「树木造型」与「村道画风试样」）。
- **街景尺度参考**：老街店前人行道宽约 4.7 m，树池临车道一侧用凸起陶砖围边，店门侧保持连续步行空间；路口与横街街具按角色身高与车宽对照摆位，不出现“巨人路灯”或“玩具门框”。

## 4. 资产生产管线边界

| 类别 | 默认生产方式 | 源与产物约定 |
|---|---|---|
| 大面积街屋壳体、道路、水体、田面、布局 | Three.js 程序化生成 + 按材质合批 | 代码在 `src/morning/`，参数集中可调 |
| 重点门面道具、街景套件、角色、植被、地标 | Blender 5.2 LTS Python 脚本生成 GLB | 源脚本与产物并置在 `art/<module>/`，必须可无头命令行复现 |
| 通用贴图与印花 | 程序化绘制脚本（Pillow / SVG）或精简贴图 | 优先顶点色 + 有限贴图；单张贴图遵循 2 的幂次尺寸，无必要不上 2K/4K |
| 店铺室内 | 复用小房间基础模板 + 特色柜台/道具区分 | 不追求室内外物理 1:1 对应 |

## 5. 性能与渲染硬预算

基线环境：Mac M2 / 中端笔记本 Chrome Metal，`1280×800`，`DPR 1`，目标稳定 **60 FPS**（数据来源：[`FIRST-ROAD.md`](FIRST-ROAD.md)）。

| 指标 | 预算 / 约束 | 核验方式 |
|---|---|---|
| 全帧 Draw Calls（含阴影） | 新增路段与城区目标 **≤ 250 calls**（老街历史追车位 310 calls 为已知超标项，新改动不得继续抬高） | Debug 面板 `#scene-perf` / `capture-scenes.mjs` |
| 全帧三角形数 | 目标 **≤ 100 万** | 性能核验与 Blender 导出面数控制 |
| 合批与实例化 | 同区块静态楼体/路面按材质合批；树木、路灯、电杆、稻穗、护柱等重复物**必须 `InstancedMesh`** | 代码审查 |
| 渲染防坑 | 禁止共面贴片导致 Z-fighting（如背板/招牌/标线需留明确法向偏移或单面剔除）；动态对象按需 `dispose` | 代码审查 + 多角度近景截图 |

## 6. UI / HUD 视觉约束

- 对白框、卡片与标签沿用 [`animal-island-ui`](../package.json) 体系与 `Noto Sans SC` 字体，圆润温暖、底部居中不遮主角。
- 所有新增或修改的 HUD / 手机 / 地图 / 对白界面，必须同时在 **PC 桌面（`1280×800`）** 和 **移动横屏（`844×390`）** 两个视口下截屏验证，确保无文字截断、按钮重叠、出屏或遮挡核心操作区。
- Debug 控件仅在开发模式、GitHub Pages 预览（`VITE_SCENE_DEBUG=1`）或 `?debug=1` 下可见；普通构建默认隐藏。
