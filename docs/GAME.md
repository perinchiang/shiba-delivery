# 阿柴快送｜当前有效游戏设计

> 本文是**唯一现行产品方向**，随明确决策原位更新；Git 保存历史，不新增 `GAME-v1.1` 之类并行规格。标记了「待验证」的内容不是已经批准实施的需求。

## 1. 产品定位【已确定】

**《阿柴快送 / Shiba Delivery》**：一款**偏严肃、带黑色幽默**的第三人称 3D 骑行送单独立游戏。可爱的动物外表，讲成年人的现实——裁员、炒股亏光、老街租房、平台算法与罚款，以及一点点往上爬的希望。

**主角阿柴**：一只被裁员的程序员柴犬。炒股失败后只剩约 3000 元，在滨海旧镇的老街住宅区租下便宜小屋，用剩下的钱买了一辆二手电动车，靠送外卖攒钱，目标是**重新住回市中心**。

**语气比例：60% 严肃的生活质感 + 40% 黑色幽默。** 幽默来自现实的荒诞（平台推送、股票 App、前同事朋友圈、订单备注），不是段子堆砌；有压力但不绝望，不走沉重的苦难路线。可爱的造型与残酷的现实形成反差，这是本作的核心辨识度。

支柱优先级：
1. **骑行本身值得玩**：速度感、穿巷子、长路飙车、稳住保温箱的技巧。
2. **升级车还是搬家的取舍有意义**：每次花钱都是一个让人犹豫的人生选择。
3. **城市在讲故事**：区域之间的贫富反差、居民、订单备注与手机里的世界。

设计取舍：新增功能若不能改善上述任一支柱，默认暂缓。

## 2. 故事结构【已确定】

- **开头即结局**：开场展示市中心的繁华，阿柴抱着纸箱走出写字楼——被裁员；手机上股票亏光、余额只剩约 3000 元。他在滨海旧镇的老街区租下便宜小屋，用剩下的钱买了电动车。第一段可玩内容就是**骑着刚买的电动车，跟着导航从市中心骑回滨海旧镇老街**（同时承担新手教学）。进入老街住宅巷时导航提示「GPS 信号弱」，引出找门玩法。
- 从老街巷口能远远望见市中心那栋写字楼——它一直是目标。
- **纸箱**作为贯穿道具：开场抱着离开，平时绑在车后，结尾再抱着走回去。
- **主线终点**：租下市中心的房子即主线结束，进入结局。此时剧情上已过去若干年。
- **三个结局**（触发条件待验证）：
  1. **回去写代码**：面试一圈产品经理岗位都被拒，最后决定重新从普通程序员做起。面试官的一句「我们现在都用 AI 写代码了」作为全作的元笑话（本作本身由 AI 协助开发）。
  2. **留下来当站长**：留在配送体系里，成为带新人的站长。
  3. **卖了车离开这座城市**。
- 通关后可继续自由骑行跑单。

**起始资金【已确定】：** 约 3000 元。旧镇老街便宜小屋月租 500 元，但「押一付三」需先付 2000 元，只剩约 1000 元，只能买一辆电池偏弱的二手电动车——开局的第一个目标自然就是换电池。

**待验证：** 剧情时间跨度的表现方式、各结局的触发条件。开场裁员与炒股过场优先用**手机屏幕 + 漫画格**呈现，控制成本。

## 3. 区域与核心取舍【方向已确定，数值待验证】

城市采用**「《如龙》式高密度方正城市箱庭 + 滨海公路串联」**结构：先打磨好 1 号起点箱庭，让玩家越跑越熟、甚至不看导航就能抄近路，再逐座扩展后续箱庭；**不做空旷野外地图**。

| 区域（城市箱庭） | 订单特点 | 风险与机遇 |
|---|---|---|
| **1 号箱庭：滨海旧镇（榕湾坡道镇）** | 单子多、单价低、距离近 | 北高南低的紧凑方正坡道网格（约 180m×180m），采用**方向 A（海滨下町 · 平顶杂居楼 + 外挂铁楼梯小巷）**：70% 2–3 层平顶水泥/瓷砖商住杂居楼（含可步行外挂铁楼梯与二楼开放式走廊门牌）+ 30% 传统木构老铺混搭，楼间打通 2.5m 穿楼小巷；坡上为住宅生活区，坡底横穿海滨电车平交道口、滨海大道与大海；GPS 会漂移，靠认门牌、记路抄近道、爬外楼梯上楼与避让电车跑出效率 |
| **2 号箱庭：现代镇区 / 商圈** | 单价正常、距离偏远 | 沿滨海大道出镇连接，跑一趟耗电更多 |
| **过渡区域**（按需扩展，待设计） | 逐级提高 | — |
| **终极箱庭：市中心** | 繁忙，神室町/现代CBD 式高楼林立，午高峰可一次接多单、批量送 | **超时罚款**；一旦接单就必须负责，否则平台扣钱 |

**双主线升级——升级车，还是搬家：**
- **升级车 / 换电池**：更快、电量更多、操控更好，可从当前住处跑去更远区域接高价单，但来回耗电耗时。
- **搬家（升级出租屋）**：把起点直接搬到更发达的区域，房租更贵、压力更大。
- 两条路都必须可行，不能出现明显的最优解。
- 区域之间约 **3–5 km 的远单是核心玩法**，长期保留五六公里级别的跨区配送。游戏内里程与实际几何长度的换算比例待首条连接路试骑后锁定。

**其他已同意的玩法：**
- **电量**：家里慢充，或在路边换电柜花钱换电池。
- **保温箱与步行搬运平衡**：汤会洒、奶茶会摇散、蛋糕会塌，不同食物对颠簸、急刹、压弯的敏感度不同，食物受损会导致投诉或扣钱。**轻量平衡灵感（待验证）**：骑行到窄巷口/台阶前下车端餐走最后一段，叠接多单或端汤水类订单时若跑太快或急转，角色与餐盒会明显晃动，收油慢走即可稳住、贪快易洒扣钱（不做硬核按键抓平衡）。
- **定位不准**：旧镇老街与围墙住宅巷内 GPS 漂移，需要靠门牌号、姓氏牌与路人指路找门；越发达的区域定位越准，但时间越紧。
- **罚款与欠款**：超时、损坏会被扣钱；租不起更好的房子就只能继续跑单补上，但不因某一天没赚够就立即 Game Over。
- **时段**：早晨、中午、傍晚、夜晚影响订单与气氛（早点单、市中心午高峰、傍晚剧情、老街宵夜单）。
- **居民与订单备注**：订单备注是主要的微型叙事载体，跨天连续的备注可串成居民故事。

**待验证：** 各区域报酬、罚款力度、房租周期、电池与车辆升级曲线、换电价格、剧情节奏、天气。

## 4. 骑手手机【方向已确定】

手机是主界面，也是黑色幽默的主要舞台。平时在骑行和步行时露出机身上沿，常显时间和当前订单目标，展开后使用各 App：

| App | 作用 |
|---|---|
| 外卖平台 | 接单、计时、罚款、平台推送（主要讽刺对象） |
| 导航 | 旧镇老街与住宅巷内会漂移 |
| 银行余额 | 收支与房租 |
| 股票 | 持续诱惑「抄底」，多数时候亏 |
| 聊天 | 房东、家人、前同事 |
| 招聘 App | 后期解锁，通向结局 |
| 相机 | 风景拍照收集 |

**当前已实现：** 订单查看、切单、接单与独立地图。其余 App 的形式待验证；股票 App、平台推送可采用廉价复古的像素界面作为笑点。

## 5. 世界、角色与车辆【已确定的方向】

- **架空东亚温暖滨海小城（榕湾）**：采用**「微缩手办级真实结构建模 × 东亚海滨生活密度 × 吉卜力/风格化 PBR 干净明媚手绘质感」**（概念锚点 [`docs/references/direction-a-seaside-zakkyo.jpg`](references/direction-a-seaside-zakkyo.jpg)，3D 工艺基准 [`art/town/haikaze-hero/Haikaze-Hero.blend`](../art/town/haikaze-hero/Haikaze-Hero.blend)，不做生锈脏旧的写实贴图）。1 号箱庭采用**方向 A（海滨下町 · 平顶杂居楼 + 外挂铁楼梯小巷）**：70% 2 层平顶商住杂居楼（一楼暖木门面/暖帘/贩卖机/墙脚杂物、可步行外挂铁楼梯、二楼开放式走廊与门牌/黄铜圆形外卖挂钩、平顶天台女儿墙与水箱晾衣绳，夜晚透出“有人居住”的室内与店面暖光）+ 30% 传统木构老铺混搭，楼间打通 2.5m 穿楼小巷，坡底是横穿海岸的绿白海滨电车平交道口、滨海大道与闪光蓝海；各箱庭用**轮廓、色调与招牌气质**区分进度：**越往市中心，颜色越冷、越整齐、越高，也越孤独**。
- **招牌与 Steam 多语言分层【已确定】**：场景店招按菜系与店型自然使用多国语言（中餐用中文、日料用日文、泰餐用泰文、市中心写字楼与西餐用英文）并搭配简笔图标，同一店铺横招/暖帘/竖牌文字保持一致且远近清晰可读；找门玩法的门牌号统一用数字/字母；UI、手机 App、订单备注、对白与门口店名提示走多语言文本表，兼顾氛围辨识度与 Steam 全球发行。
- **全面定调「纯 Blender 精建 + AI 手绘 2D PBR 贴图 + 全游戏共享公模库 → Godot 4.7 原生 `.blend` 直导」管线**：彻底淘汰早期纯代码方块建筑、纯顶点色假材质、程序化 Canvas 贴图与 WebGL 低采样光图烘培；建筑、街头/室内道具、载具与后续 NPC 统一由 Blender 精建母版 + AI 手绘 PBR 贴图产出，通用道具归口 [`art/shared/props/`](../art/shared/props/) 支持一键换色/换贴图复用（开工前必查 [`art/CATALOG.md`](../art/CATALOG.md)），走「Gate 1 Blender Cycles 日/夜审图 → Gate 2 Godot 4.7 Forward+ 原生 `.blend` 直导与实时 AgX / VoxelGI / SSIL / SSAO / 软阴影实机验收」两关流程。具体规范见 [`ART-BIBLE.md`](ART-BIBLE.md)。
- **老街与住宅区需要可骑入的紧凑窄巷**；窄路与近墙同时服务速度感。
- 世界应当视觉上完整、制作上有选择：大量建筑只需可信外立面与真窗洞室内纵深；少量有订单、故事或功能价值的地点允许进入。玩家接单后必须能识别正确入口。店铺与住宅室内使用独立、可复用的小房间模板。
- **出租屋**是主要的情感进度：旧镇老街便宜小屋 → 现代镇区小公寓 → 市中心；每处是独立小室内（起点/终点、充电、睡觉、看账单）。
- **阿柴主角（2.5 头身微缩手办定型，已实装）**：采用 Blender 5.2 + AI 手绘短绒毛发与防风衣 PBR 贴图精建（[`art/shared/characters/shiba/Shiba-Hero.blend`](../art/shared/characters/shiba/Shiba-Hero.blend)，`1.0` 真世界米制：耳尖总高 `1.26m`、贴头复古明黄半盔宽 `0.48m`，与海风庄 1.15m 外楼梯与 2F 门廊严丝合缝），配豆豆眉、腮红、3D `ω` 微笑、可翻转航空护目镜（站/走/爬楼梯自动翻上额头，骑车自动翻下护眼）、黄黑反光条外卖防风衣、爪印胸章与柔顺 3 骨卷尾，内置 `Stand`/`Walk`/`StairClimb`/`Ride`/`Mount`/`Dismount` 6 组平滑骨骼动画并原生直导入 Godot 4.7。
- **NPC 居民**共用同一套 2.5 头身身体骨架与动画，以头、耳、尾、毛色、服装区分物种（待试点，归口 `art/shared/characters/`）。
- **车辆是平踏板电动摩托**，开局为二手车。车辆升级路线以**多款不同的电动车**呈现（速度、电量、操控与外观各有取舍），而不只是数值升级；具体车型待设计。**已敲定方案 A（圆润复古平踏板二手电动车，下一步立即精建替换旧 `monkey-delivery.glb`）**：造型承接方向 A 概念图（[`docs/references/direction-a-seaside-zakkyo.jpg`](references/direction-a-seaside-zakkyo.jpg)）的圆润明黄复古踏板审美，同时融入实用外卖车结构（平踏板、前购物挂钩、把立手机支架、后双减震、侧撑、后货架与外卖保温箱，以及**预留可掀开座垫 + 提手可拆电池仓**，为后续换电池动画与换电柜玩法做好真结构准备）。

## 6. 骑行手感【方向已确定，参数待验证】

- 目标：起步轻快、开阔路段可提速、弯前有时间收油；清楚的加速曲线、过弯倾斜、随速度变化的镜头与风声胎噪。窄巷与长连接路分别提供「贴墙穿行」与「放开飙车」两种速度感。
- 当前实现：默认最高速度 50 km/h，低速强起步、车速上升后推力减弱；高速打方向更缓，松手较快回正；按 S 或下拉摇杆先刹停，停稳后继续按住 0.35 秒开始倒车；后轮加速扬尘、制动压弯留胎印。调试时可切换 32.4、25、35 km/h 对照。
- 车辆升级后的速度、电量、操控数值待验证。
- **摄像机统一**：所有区域共用同一套骑行跟随与步行镜头规则，不再按场景各调一套。室外支持鼠标/触控 360° 拖动视角（`[`/`]` 微调、`R` 或双击回正；骑行开动松手约 1.5 秒后回正到车尾）。

## 7. 发行与开发方式【已确定】

- **正式发行与开发主干均采用 Godot 4.7 Desktop（Forward+ · PC / Steam 优先）**，原生支持 Windows / macOS / Steam Deck、手柄、原生物理与高端实时光照，不再维护 WebGL 浏览器降级版本。
- **远程手机验收方式**：每次完成阶段开发，自动在 GitHub Pages 固定外网首页（https://perinchiang.github.io/shiba-delivery/）发布一份移动友好的 **HTML 图文进度报告**（写明改动内容、实机性能读数、同机位对比与实机截图、Own Calls 与待拍板项），方便 Patrick 在外跑外卖时随时用手机快速验收。
- 开发期在桌面端保留可折叠的 **Debug 面板**（默认收起，`Tab`/`F12` 展开），支持 4 时段实时切换、Cycles 同款审图机位、瞬移至已实现地点与实时 FPS/Draw Calls 显示；正式 Steam 发行时默认隐藏。

- **首版可玩骑行、爬楼梯与送单闭环**：支持 `WASD` 骑行压弯、360° 拖动环视、`E` 键下车沿 14 级外挂铁楼梯走上 2F 201/202 走廊，并跑通「1F 海风拉面取餐 → 爬外楼梯挂到 201/202 室门口黄铜挂钩 / 骑车送至海滨观海护栏 → 余额累计结算」最小送单闭环。
- **4 时段实时光照**：支持清晨 / 中午 / 傍晚 / 夜晚实时切换，含 13 组动态自发光材质、6 盏广角夜景实用灯与夜间小摩托头灯。
- **待继续扩建**：周边尚未补齐同工艺的 Blender 杂居楼/商铺/海滨电车与踏切，主角开局载具仍暂用旧版小摩托（待按同管线替换圆润明黄二手电动车），骑手手机多 App 与黑色幽默账单系统待后续接入。

后续阶段顺序与过关标准见 [ROADMAP](ROADMAP.md)。

## 9. 已确定的产品边界

1. **语气**：60% 严肃生活质感 + 40% 黑色幽默。
2. **结构**：主线（租回市中心）+ 三结局 + 通关后可继续自由跑单。
3. **最小可玩版本**：滨海旧镇起点（老街 + 独栋住宅区）+ 一条连接路 + 现代镇区/商圈（简版），用于验证「升级车还是搬家」的取舍。
4. **骑行与交通**：80% 街机轻快 + 20% 压弯/刹车反馈；**不做真实车流阻挡与闯红灯罚款**（红绿灯作为街景氛围）。
5. **目标时长**：约 3–6 小时完整通关（待最小可玩版本验证后复核）。

## 10. 当前明确不做 / 不自动扩张

- 不做「所有店铺可进入、所有房间真实存在」的重型开放世界。
- 不做地域写实复刻，**保持吉卜力柔和厚涂的干净明媚质感，不做生锈脏旧的写实风格**；不为每栋建筑单独建模。
- 不做空旷大野外地图（稻田、河桥、乡道与边缘风车村不再扩建；自然风景通过海滨坡道箱庭背后的山坡绿草与面向大海的视野自然融入城中）。
- 不叠加饥饿、疲劳、健康、心情等复杂数值；初期核心资源为**金钱、时间、电量**。
- 不做真实车流阻挡与闯红灯罚款。
- 不做全屏像素风，也不做全场景卡通描边（S1 实测结论见 `ART-BIBLE.md` §2）；像素风只可用于手机内的个别 App 界面。
- 不再维护 WebGL 浏览器降级试玩版；开发远程进度验收通过 GitHub Pages 外网 HTML 图文报告门户完成，实机游玩的体验聚焦 PC / Steam 原生桌面端。
- 不因为脑暴、历史 Commit 或旧文档提过某项功能，就自动恢复或启动开发（包括已取消的「治愈动物小镇」定位）。

任何明确决定变更，都应在同一任务中原位更新本文；实现状态应以实际代码和测试为准。
