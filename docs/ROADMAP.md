# 阿柴快送｜开发路线

> 本文只管**先做什么、做到什么程度算过关**；游戏要做成什么样以 [`GAME.md`](GAME.md) 为准，两者不互相复制。阶段完成或顺序调整时原位更新本文，不另开新版本。

## 当前原则

- **先定风格，再大量生产。** 渲染风格与时段系统定稿前，不批量制作新区域资产，避免整体返工。
- **最小可玩版本 = 滨海旧镇起点（老街 + 独栋住宅区） + 一条连接路 + 现代镇区/商圈（简版）**，只为回答一个问题：「升级车还是搬家」是否让人纠结。
- **野外与角色冻结。** 乡道样段和阿柴造型保持现状，Demo 前再统一精修。
- 每个阶段都是**可玩的完整体验**，并维护对应的开发期 Debug 瞬移入口。
- 渲染与 3D 预算以 [`ART-BIBLE.md`](ART-BIBLE.md) §5 为准（≤ 250 calls、≤ 100 万三角形、60 FPS）。

### M0 · 地基整理（已完成）

订单、地点、室内房间数据驱动；场景瞬移注册表；按职责拆分 `main.js`；Debug 面板显示 FPS 与 draw call。

### 早期原型（已完成，冻结）

- **已交付：** 老街药店单、包子早餐单（含进店取货）；十字路口与南北横街 3 张城区订单、5 位 NPC、二维路口导航、城区地图、连续接单；全时自由骑行/步行；约 1.25 km 乡道与稻田美术样段及调试机位；50 km/h 默认限速、过弯倾斜、随速镜头、风声胎噪、扬尘胎印、区域环境声与循环音乐。乡道试骑记录见 [`FIRST-ROAD.md`](FIRST-ROAD.md)。
- **冻结说明：** 野外不在最小可玩版本范围内；**老街作为游戏起点区域（主角便宜小屋所在）**，在 S1 收尾阶段改接到十字路口末端左转进入，具体建筑与模块升级在 S2 展开。

### S2 · 旧镇起点切片

- **3D 样角先行**：跳过 2D paintover，先做约 **10m × 10m 的 3D 样角切片**（Blender 倒角 + 顶点色 AO），在实机中确认材质、比例、Draw Calls 与骑行手感后再批量生产。
- Blender 旧镇模块套件 v1（约 15–25 个模块：以 4 栋一组的方格式围墙小独栋+小院+门牌/姓氏牌为住宅基本单元，配老街门面、圆润空调外机、电线，全带倒角与顶点色 AO，预留自发光区域；干净温暖、不做脏旧生锈质感）。
- 接入程序化多语种招牌图集（按菜系/店型使用中/日/泰/英 + 简笔图标；门牌号用数字/字母）。
- 主角老街便宜小屋室内（起点/终点、充电、睡觉、看账单）。
- 找门玩法：GPS 漂移、门牌号/姓氏牌、路人指路。
- 车辆替换为开局的二手电动车（保留现有接触锚点）；后续车型在 S3 车辆升级中设计。

**过关：** 这块滨海旧镇（老街 + 围墙小独栋）可直接当宣传截图；玩家能靠门牌与指路完成一次找门送达；性能达标。

### S3 · 最小可玩版本

- 滨海旧镇起点到现代镇区/商圈约 3–5 km 的连接路（程序化，服务高速骑行）与现代镇区/商圈（简版）。
- 电量消耗、家里充电与换电柜；车辆升级（多款电动车 / 换电池）；搬家到现代镇区；房租周期；超时与损坏扣钱；保温箱晃动与食物受损。
- 游戏内里程与实际几何长度的换算比例锁定后回写 `GAME.md`。

**过关：** 一局 30–45 分钟，玩家至少一次真正犹豫「升级电池跑过去」还是「咬牙搬过去」。

### S4 · 开场与人

- 开场：市中心英文写字楼（傍晚/雨夜，单程固定路线）+ 手机屏幕与漫画格过场 + 骑回滨海旧镇老街的教学骑行。
- 手机 App：平台推送、银行余额、股票、聊天。
- 3–4 位居民的跨天订单备注故事；NPC 共享身体骨架试点。

**过关：** 试玩者能复述阿柴为什么在送外卖，并记得至少两位居民。

### S5 · Steam Demo

- Demo 从开场到「搬到现代镇区」为止（约 30–60 分钟）；手柄支持、设置菜单（画质、音量、按键）、多语言 UI 文本接入。
- 锁定 Steam 打包方式，在真实 PC 上测试性能；商店页、预告片与截图，目标参加一次 Steam 新品节。
