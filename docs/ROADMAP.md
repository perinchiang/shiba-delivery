# 阿柴快送｜开发路线

> 本文只管**先做什么、做到什么程度算过关**；游戏要做成什么样以 [`GAME.md`](GAME.md) 为准，两者不互相复制。阶段完成或顺序调整时原位更新本文，不另开新版本。

## 当前原则

- **先打磨好 1 号方正箱庭，再连下一座城。** 采用《如龙》式高密度城市箱庭思路，先让 1 号箱庭「榕湾海滨坡道镇」做到好看、好认路、越跑越熟且打工循环成立，再沿滨海大道接出第 2 座箱庭。
- **彻底重构旧拼缝，不再往旧老街补丁上硬改。** 旧老街与旧十字路口为两套独立拼接坐标，S2 直接以统一高度场与道路网格的新海滨坡道箱庭替代，待迁移完成后移除旧场景代码。
- **不做空旷野外，角色造型冻结。** 乡道样段与边缘风车村仅保留于 Debug 入口参考；阿柴造型保持现状，Demo 前再统一精修。
- **最小可玩版本 = 1 号箱庭（榕湾海滨坡道旧镇） + 滨海连接路 + 2 号箱庭（现代镇区/商圈简版）**，只为回答一个问题：「升级车还是搬家」是否让人纠结。
- 每个阶段都是**可玩的完整体验**，并维护对应的开发期 Debug 瞬移入口。
- 渲染与 3D 预算以 [`ART-BIBLE.md`](ART-BIBLE.md) §5 为准（≤ 250 calls、≤ 100 万三角形、60 FPS）。

### M0 · 地基整理（已完成）

订单、地点、室内房间数据驱动；场景瞬移注册表；按职责拆分 `main.js`；Debug 面板显示 FPS 与 draw call。

### 早期原型（已完成，冻结）

- **已交付：** 老街药店单、包子早餐单（含进店取货）；十字路口与南北横街 3 张城区订单、5 位 NPC、二维路口导航、城区地图、连续接单；全时自由骑行/步行；约 1.25 km 乡道与稻田美术样段及调试机位；50 km/h 默认限速、过弯倾斜、随速镜头、风声胎噪、扬尘胎印、区域环境声与循环音乐。乡道试骑记录见 [`FIRST-ROAD.md`](FIRST-ROAD.md)。
- **冻结说明：** 不再打磨野外，也不再修补旧老街与旧十字路口之间的硬拼接；待 S2 新海滨坡道箱庭接管全部送单与入口后整体下线旧场景。

### S2 · 1 号箱庭：榕湾海滨坡道镇（进行中）

- **步骤 1 · 箱庭骨架与方向 A 标杆建筑定调**：
  - 全新统一高度场 + 统一道路与碰撞网格（约 `180m × 180m` 方正网格，彻底告别断层与跨界卡顿）：北侧绿草山坡挡土墙 → 坡上住宅生活区与窄巷 → 顺坡下冲的商业老街与镇中心十字小广场 → 坡底定时驶过的绿白海滨电车与平交道口（踏切）→ 滨海大道与观海人行道 → 闪光蓝海与远岸市中心高楼剪影。
  - **已定建筑大方向（方向 A · 海滨下町平顶杂居楼 + 外挂铁楼梯小巷）**，视觉锚点图见 [`docs/references/direction-a-seaside-zakkyo.jpg`](references/direction-a-seaside-zakkyo.jpg)：采用 **70% 2–3 层平顶水泥/瓷砖商住杂居楼 + 30% 传统木构老铺混搭**，引入可真实步行的外挂烤漆钢铁楼梯、二楼开放式走廊与 2.5m 穿楼小巷。
  - **先单栋标杆定调，再整镇模块化铺开**：先打磨好 1 号标杆建筑 **「海风庄 · 2.5 层平顶外挂铁楼梯商住楼」**（1F 拉面小铺/红暖帘/单车/饮料筐/拐角自发光贩卖机 + 外挂墨绿铁楼梯 + 2F 201/202 开放式走廊/排水管/空调外机 + 平顶女儿墙护栏 + 东侧 2.5m 穿楼小巷），实机确认白天/傍晚/夜晚与步行上楼体验满意后，再按该工艺拆成方向 A 模块套件升级整片街区并扩展穿楼小巷网。
  - 先作为默认入口上线验证手感与画面，旧老街/旧十字路口暂留 Debug 瞬移对比；风车村样段（[`hillside-village.py`](../art/town/hillside-village.py)）归档为远郊村落参考。
- **步骤 2 · 玩法接管与第一版黑色幽默打工循环**：
  - 接入多语种招牌图集与数字/字母门牌（含外楼梯二楼门牌 201/202），把取餐/送餐、找门玩法（GPS 漂移 + 门牌号 + 捷径窄巷 + 爬外楼梯上二楼敲门）迁移进 1 号箱庭，完成后删除旧老街/旧十字路口历史代码。
  - 主角坡上便宜小屋室内（起点/终点、充电、睡觉、看账单）与第一版黑色幽默打工循环（上线扣 ¥3 安心险、超时按比例扣钱、电量消耗与推车焦虑）。
  - **开局二手电动车替换（暂不着急，待核心箱庭与打工循环稳固后或 S3 择机推进）**：参考已存档的方向 A 概念图明黄圆润踏板电动车造型（[`docs/references/direction-a-seaside-zakkyo.jpg`](references/direction-a-seaside-zakkyo.jpg)）与姊妹项目 `neon-delivery` 车辆实现（`documents/game/neon-delivery/src/vehicle/moped.js`、`mopedparts.js`）制作阿柴的二手电动车并替换现有带排气管的小摩托（保留既有座位、握把、脚踏与餐箱接触锚点）；后续更多车型在 S3 车辆升级中扩展。

**过关：** 1 号海滨坡道箱庭可直接当 Steam 商店页宣传截图；玩家在镇里能越跑越熟、靠认路抄近道与门牌完成取餐送餐，并体验到黑色幽默打工循环；全机位 ≤ 250 calls、60 FPS。

### S3 · 最小可玩版本

- 滨海旧镇起点到现代镇区/商圈约 3–5 km 的连接路（程序化，服务高速骑行）与现代镇区/商圈（简版）。
- 电量消耗、家里充电与换电柜；车辆升级（多款电动车 / 换电池）；搬家到现代镇区；房租周期；超时与损坏扣钱；保温箱晃动与食物受损。
- 游戏内里程与实际几何长度的换算比例锁定后回写 `GAME.md`。

**过关：** 一局 30–45 分钟，玩家至少一次真正犹豫「升级电池跑过去」还是「咬牙搬过去」。

### S4 · 开场与人

- 开场：市中心英文写字楼（傍晚/雨夜，单程固定路线）+ 手机屏幕与漫画格过场 + 骑回滨海旧镇老街的教学骑行。
- 手机 App：平台推送、银行余额、股票、聊天。
- 3–4 位居民的跨天订单备注故事；NPC 共享身体骨架试点。

**过关：** 试玩者能复述阿柴为什么在送外卖，并记得至少两位居民。

### S5 · Steam Demo

- Demo 从开场到「搬到现代镇区」为止（约 30–60 分钟）；手柄支持、设置菜单（画质、音量、按键）、多语言 UI 文本接入。
- 锁定 Steam 打包方式，在真实 PC 上测试性能；商店页、预告片与截图，目标参加一次 Steam 新品节。
