# 阿柴快送｜开发路线

> 本文只管**先做什么、做到什么程度算过关**；游戏要做成什么样以 [`GAME.md`](GAME.md) 为准，两者不互相复制。阶段完成或顺序调整时原位更新本文，不另开新版本。

## 当前原则

- **重心是「一条值得骑的路」。** 现有 1.25 km 村道已可往返试骑。M1 过关前，新内容优先服务手感、风景节奏和性能验证。
- **角色精修服务于骑行。** M1 增加起步、制动、路面反馈和高速骑姿。已有造型与上下车动作作为基线，M3 前仅在出现接触错误时调整。
- 每个阶段都是**可玩的完整体验**，并维护对应的开发期 Debug 瞬移入口。
- 当前车速与手感**不是最终版本**，在 M1 重新设计。

### M0 · 地基整理

- 订单、地点、室内房间改为数据驱动：一单一份配置（取货点、送达点、物品、店员、台词、报酬）。
- 场景瞬移改为注册表，新场景登记后自动出现在 Debug 面板。
- 按职责拆分 `src/morning/main.js`（骑行、步行、订单流程、UI、相机）。
- Debug 面板显示 FPS 与 draw call，作为后续性能预算基线。

**过关：** 加第三张订单只需新增配置并复用室内模板，不改主循环；现有药店单、包子单、触屏与键盘操作、瞬移和测试行为不变。

### M1 · 第一条路

- 从老街骑出镇口，经过开阔稻田、河边小桥，抵达村口，约 1–1.5 km。
- 道路样条（弯道、坡度、路面变化），沿路程序化生成楼体、围墙、田埂；植被与路灯实例化，远景简化。
- 以 32.4 km/h 为对照，测试默认 50 km/h 村道档。保留利落的 0–30 km/h 起步，30–50 km/h 逐渐收力；实测刹距、连续弯和桥头视距后确定巡航速度。
- 环境声随区域切换（街市、稻田蛙鸣、水声），放一段骑行背景音乐验证气氛；清晨时段光照。
- 确定车速、游戏内时间流速与地图尺度的换算关系，写回 `GAME.md`。

**已交付：** 无订单自由骑行、村道地图、现场限速切换、过弯倾斜、随速镜头、风声胎噪、区域环境声与循环音乐；沿线地标与稻田样段瞬移。

**稻田入弯到石桥桥头的精修样段：** 通过「场景瞬移 → 稻浪到石桥」进场，用默认 50 km/h 及 32.4 km/h 对比。检查石牛与桥栏在入桥前的辨识度、正常后视下的稻浪、起步与刹车的重心转移，以及前后轮过桥缝时的先后响应。「田埂看稻穗」供近景材质比对。

**尚待玩家判断：** 哪一档值得作为默认巡航速度、骑手回弹是否自然、这套田园美术能否扩展到全线。在样段验收前，维持当前制作范围。

**过关：** 没有订单时，试玩者愿意自己来回骑 3 分钟以上；中端笔记本浏览器稳定 60 fps。

### M2 · 完整的一天

- 阿柴的出租屋作为起点和终点：充电、睡觉、看账单。
- 一个早班 3–5 单，含老街近单和一张到村口的远单；接单时显示报酬、距离与预计耗时。
- 真实时钟、电量（骑行消耗、在家或充电桩补电）与现金。
- 收工结算：今日收入、充电支出、距下次交租还差多少。

**过关：** 一局 20–30 分钟，玩家至少面对一次「近单还是远单」的真实取舍。

### M3 · 小镇有人

- 3–4 位回头客动物居民，每人一条跨多天的小故事；以已有猴子骑手资产试点第二物种的骨架复用。
- 交付方式多样化：当面交、放门口，以及复用的小区大堂、电梯、楼层走廊模板。
- 新增一间店铺，验证「程序化楼体 + Blender 门面」的制作成本。
- 居民好评原型（取代平台星级）。

**过关：** 试玩者能说出至少两位居民的名字和他们的事。

### M4 · 一周生活

- 多日存档，以周为单位交房租；欠租、宽限、向居民借钱或小额贷款的最简原型。
- 由经济状况触发的居民事件；调校近单、远单、空跑返程与充电成本。
- 车辆小升级首批（外观优先）。

**过关：** 一周玩下来，至少出现一次因为缺钱而做出的有意思的选择，而不只是刷钱。

### M5 · Steam Demo

- 30–60 分钟 Demo、手柄支持、设置菜单（画质、音量、按键）。
- 锁定发行打包技术并在真实 PC 上测试性能。
- Steam 商店页、预告片与截图，目标参加一次 Steam 新品节。

## 未排期但已同意的方向

骑行电台、风景拍照收集、天气与时段变化（见 `GAME.md` §5）。在 M1–M4 中视验证结果插入，不单独开阶段。
