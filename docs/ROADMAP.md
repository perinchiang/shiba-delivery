# 阿柴快送｜开发路线

> 本文只管**先做什么、做到什么程度算过关**；游戏要做成什么样以 [`GAME.md`](GAME.md) 为准，两者不互相复制。阶段完成或顺序调整时原位更新本文，不另开新版本。

## 当前原则

- **重心是「一条值得骑的路」。** 现有 1.25 km 村道已可往返试骑。M1 过关前，新内容优先服务手感、风景节奏和性能验证。
- **角色精修服务于骑行。** M1 增加起步、制动、路面反馈和高速骑姿。已有造型与上下车动作作为基线，M3 前仅在出现接触错误时调整。
- 每个阶段都是**可玩的完整体验**，并维护对应的开发期 Debug 瞬移入口。
- 自由骑行默认最高速度已确定为 **50 km/h**，M1 继续验证制动、过弯和路面反馈。

### M0 · 地基整理

- 订单、地点、室内房间改为数据驱动：一单一份配置（取货点、送达点、物品、店员、台词、报酬）。
- 场景瞬移改为注册表，新场景登记后自动出现在 Debug 面板。
- 按职责拆分 `src/morning/main.js`（骑行、步行、订单流程、UI、相机）。
- Debug 面板显示 FPS 与 draw call，作为后续性能预算基线。

**过关：** 加第三张订单只需新增配置并复用室内模板，不改主循环；现有药店单、包子单、触屏与键盘操作、瞬移和测试行为不变。

### M1 · 第一条路

- 从老街骑出镇口，经过开阔稻田、河边小桥，抵达村口，约 1–1.5 km。
- 道路样条（弯道、坡度、路面变化），沿路程序化生成楼体、围墙、田埂；植被与路灯实例化，远景简化。
- 默认 50 km/h，保留利落的 0–30 km/h 起步，30–50 km/h 逐渐收力。在城市十字路口验证弯前减速、转入横街和出弯加速时的后轮反馈。
- 环境声随区域切换（街市、稻田蛙鸣、水声），放一段骑行背景音乐验证气氛；清晨时段光照。
- 车速、游戏内时间流速与地图尺度的换算关系仍待首条长路段玩家测试后锁定，锁定后回写 `GAME.md`。

**已交付：** 无订单自由骑行、村道地图、现场限速切换、过弯倾斜、随速镜头、风声胎噪、区域环境声与循环音乐；沿线地标与稻田样段瞬移。老街东端已接入可直行、左右转的城市十字路口，后轮在加速、制动和过弯时给出可见反馈。
- **稻田路段美术样段：** 桥前约 166 米的稻田使用连续田面、绘制稻穗与疏密过渡，加入「稻田风景」独立机位；其中约 64 米样板路段完成路面、窄路肩、下切沟边、田埂和根部区的高低连接，首排稻穗稀疏错落并由路肩和低矮植被遮根；骑行、碰撞、订单和调试入口保持可用。

**村道画风样板与「稻浪到石桥」精修段：** 通过「场景瞬移 → 开阔水田 / 稻浪到石桥 / 河边小桥 / 村口」分区域核验路面标线、土路肩、河水和清晨光影。「田埂看稻穗」供近景观察。样板路段另提供「路肩样板·骑行 / 斜视 / 田边下车」三张固定机位，用于核验道路压高、沟边下切、田埂遮根和作物纵深。试骑用默认 50 km/h 和 32.4 km/h 对比稻浪的包围感与回摆、石牛和桥栏在进桥前的辨识度、起步刹车的重心转移，以及双轮过桥缝的先后响应。

**尚待玩家判断：** 在路口减速和压弯时，胎印和扬尘能否读出轻重；骑手回弹是否自然；乡道样段的骑行节奏、色温和细节密度是否合适，以及是否值得推广到其他路段。

**过关：** 没有订单时，试玩者愿意自己来回骑 3 分钟以上；中端笔记本浏览器稳定 60 fps。

### M2 · 完整的一天

- **已交付（城区送单闭环与体验精修）：** 打通老街与城市十字路口及南北横街的连续骑行接单，新增南方冰室、海棠茶行、春风书局 3 张门口交接城区订单、5 位动物店主/居民、二维路口转弯导航、全城区地图及送完不重置原地的连续接单与累计到手统计；老街建筑比例与十字路口街景样板同步完成。并已升级为全时自由行动（取消独立「自由骑行」开关，开局与送完单均可直接骑行/步行）、十字路口第三人称透视步行镜头与屏幕相对方向行走（含防遮挡与地面接缝/穿模修复）、阿柴圆润落肩袖与自然摆臂步行、摩托厚实棱纹坐包/立体风冷发动机/上扬防烫排气管，以及加宽三格后开门保温箱与平推装取餐动画。
- **待交付：** 阿柴出租屋（起点/终点、充电、睡觉、看账单）、含村口远单的同屏选单、流动时钟与电量消耗/充电桩、收工日结与距房租差额。
- **下一步美术管线试点（已确认顺序）：** 在城区送单闭环之上，优先用 Blender 脚本产出 `city-street-kit.glb`（红绿灯/路灯/邮筒/长椅/护柱/井盖），再试点 1 间“换壳换道具”特色店面（如花店）与可复用深凹槽街屋模块。

**过关：** 一局 20–30 分钟，玩家至少面对一次「近单还是远单」的真实取舍。

### M3 · 小镇有人

- 3–4 位回头客动物居民，每人一条跨多天的小故事；以已有猴子骑手资产试点第二物种的骨架复用。
- 交付方式多样化：当面交、放门口，以及复用的小区大堂、电梯、楼层走廊模板。
- 新增一间店铺，验证「程序化楼体 + Blender 门面」的制作成本。
- 居民好评原型（取代平台星级）。

**过关：** 试玩者能说出至少两位居民的名字和他们的事。

### M4 · 一周生活

- 多日存档，以周为单位交房租；欠租、宽限、向居民借钱或小额贷款的最简原型。
- 由经济状况触发的居民事件；调校近单、远单、空跑返程与充电成本。
- 车辆小升级首批（外观优先）。

**过关：** 一周玩下来，至少出现一次因为缺钱而做出的有意思的选择，而不只是刷钱。

### M5 · Steam Demo

- 30–60 分钟 Demo、手柄支持、设置菜单（画质、音量、按键）。
- 锁定发行打包技术并在真实 PC 上测试性能。
- Steam 商店页、预告片与截图，目标参加一次 Steam 新品节。

## 未排期但已同意的方向

骑行电台、风景拍照收集、天气与时段变化（见 `GAME.md` §5）。在 M1–M4 中视验证结果插入，不单独开阶段。
